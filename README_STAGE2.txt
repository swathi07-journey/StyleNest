STYLENEST – STAGE 2 ADD-ON

How to install:
1. Open your existing StyleNest folder (the one containing index.html, css, and js).
2. Copy shop.html into the main StyleNest folder.
3. Copy the css/shop.css file into your existing css folder.
4. Copy js/products.js and js/shop.js into your existing js folder.
5. Do not delete or replace your Stage 1 files.

Important:
- Keep your Stage 1 js/main.js; it injects the shared header/footer.
- Open shop.html using Live Server.
- Search, filters, sort, load more, wishlist toggles, and demo Add to Cart are included.
- Product cards link to product.html, which will be created in a later stage.
- Cart/wishlist are demo LocalStorage only; no real payments or customer accounts.

STYLENEST - STAGE 7: WISHLIST

FILES
- wishlist.html -> copy to your main StyleNest folder
- css/wishlist.css -> copy to StyleNest/css/
- js/wishlist.js -> copy to StyleNest/js/

IMPORTANT
1. Keep your existing css/style.css and js/main.js files. Do not replace them.
2. This page uses the same LocalStorage key already used by Stage 3: stylenest_wishlist.
3. Open wishlist.html using Live Server to test.
4. Add a product to wishlist from its Product Details page, then open wishlist.html.
5. Test the remove button and View Product links.

NAVIGATION
If your shared header does not already have a Wishlist link, add a link to wishlist.html in the existing navigation in js/main.js. Do not replace the whole main.js file.

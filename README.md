# StyleNest — Stage 1

A responsive fashion-store homepage built with HTML5, CSS3 and vanilla JavaScript, styled to match the approved StyleNest eight-page visual direction.

## Run locally
1. Extract the `stylenest` folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Internet access is needed for Google Fonts and the remote Unsplash demo photos.

## Stage 1 includes
- Responsive homepage layout
- Shared header and footer rendered from `js/main.js`
- Mobile navigation toggle
- Category, trending, new-arrival, benefits, reviews and newsletter sections
- Newsletter email validation and preview toast feedback

## Current demo limitations
Shop, cart, wishlist and account links are visual navigation placeholders at this stage. Their real pages and functionality will be added in later stages. The product cards are homepage previews, not connected to product data yet.

## Image note
Homepage photos are loaded from Unsplash image URLs for this portfolio demonstration. Replace them with licensed/local assets before commercial use.

## Next stage
